# 🎬 Visualización de Videos mediante iFrame en HTML

Este repositorio contiene una implementación básica en HTML5 que demuestra cómo integrar y reproducir contenido multimedia de plataformas externas (como YouTube) en una página web mediante la etiqueta `<iframe>`.

---

## 🚀 Características

* **Incrustación de Video:** Uso de la etiqueta `<iframe>` para renderizar reproductores de video directamente en la página.
* **Configuración de Permisos:** Implementación de atributos de seguridad y reproducción como `allowfullscreen`, `autoplay`, `accelerometer` y política de origen cruzado (`referrerpolicy`).
* **Estructura Simple:** Documento HTML5 ligero e intuitivo, ideal para pruebas rápidas y proyectos educativos.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Etiqueta `<iframe>` y marcado semántico básico.
